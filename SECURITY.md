# Security Policy

## Supported versions

Security fixes are applied to the current `0.1.x` development line. This
project has not yet published a stable npm release.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use
GitHub's private vulnerability reporting for this repository. If that option
is unavailable, contact the Terminal Research maintainers through an existing
private support channel.

Do not include live access tokens, file-grant URLs, private Agent Cards, or
conversation content in an initial report. The maintainers can arrange a safe
way to exchange sensitive reproduction material when it is necessary.

The React package is not an authorization boundary. Aion API deployments must
continue to authenticate and authorize catalog, conversation, upload, and A2A
operations on the server.
